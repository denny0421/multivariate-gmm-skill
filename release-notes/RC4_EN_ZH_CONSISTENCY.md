# rc4 英文與繁體中文報告一致性報告

**檢查方式：** 同一個分析分別產生英文（`--lang en`）和繁體中文（`--lang zh-TW`）報告，同時用 rc3 產生英文報告作為基準。所有檢查都由 R 程式自動進行，結果在 `rc4_test_log.txt`。

## 檢查規則

| 項目 | 規則 |
|---|---|
| 英文報告與 rc3 相同 | 遮蔽「產生時間」和「程式檢查碼清單」之後逐行相同 |
| 表格 | 英文的每一張 Markdown 表（`md_table()` 輸出）都必須原樣出現在中文版中 |
| 內文數值 | 英文內文（不含表格、檢查碼、產生時間）中的每個數字都必須出現在中文版 |
| 代碼 | 英文中的每個代碼（例如 `S3-07`、`SMALL_COMPONENT`、`S6_STRATA`）都必須出現在中文版 |
| 英文原句 | 第 11.1 節自動診斷的每一句英文原文，都必須原樣引用在中文版 |
| 圖 | 兩種語言引用的圖檔相同，中文版每張圖都有「圖說」 |
| 來源 | 兩份 `report_manifest.json` 的 `sources`（檔名、MD5、SHA-256）相同 |
| 其他輸出 | `pending_heuristics.csv`、`warnings_registry_snapshot.csv` 和 `figures/` 逐位元相同 |
| 分析不受影響 | 產生報告前後，分析資料夾中除了 report 和狀態檔之外的所有檔案雜湊不變；狀態檔只新增 `report_lang` |

## 中文版較英文版多出的內容

這些內容都依現有的結果或代碼產生，沒有新增門檻或結論：

- 開頭「本報告怎麼讀」，以及各節的白話說明；
- 表格下方的中文欄位說明；
- 各代碼的中文說明；
- 第 4 節的檢查項目中文名，以及附錄 A 的中文說明表；
- ARI／NMI 在 B、C、S、D 四種情況下的「不適合直接解讀」說明；
- 選定 G = 1 時的「沒有證據支持分成多個混合成分」；
- 第 12 節的報告語言說明。

## 已知的呈現差異

- **NA 與 NaN：** 中文版顯示原值 `NA`、`NaN`，英文版顯示 `-`。兩者是同一個原始值，沒有被替換成其他數字。
- **ARI／NMI 的小數位數：** 中文版沿用英文版的位數，各節 4 位，結論 3 位。
